Connections

Three separate systems. Two bring information in so you never research or contact a domain twice. One sends finished results out.

Reads in

Research sources

Read-only lists you already own. Every tab is checked before a website is opened. The tool never writes here. If an enabled source cannot be read, research waits rather than treating an old contact as new.

Added Sheets name themselves and check themselves. You do not need to refresh them by hand.

Reads in

Email history

Checks each mailbox's Sent folder so a domain you already emailed is skipped. Only yes/no, the date and the matched address come back — no email content ever leaves Gmail.

Connect a Gmail account
  1. Sign in to that Gmail account and open script.google.com, then New project.
  2. Paste the same Code.gs and appsscript.json from the sheets-apps-script folder.
  3. Deploy as a Web app (Execute as: Me, Access: Anyone) and paste the /exec URL below.
Writes out

Output destination

The one Sheet finished results are written to. Rows are matched by domain and campaign, so re-sending updates a row instead of duplicating it, and your own Status and Notes columns are never overwritten.

How to set it up (5 minutes)
  1. Create a new Google Sheet. Open Extensions, then Apps Script.
  2. Paste Code.gs from the sheets-apps-script folder. In Project Settings, tick “Show appsscript.json” and paste that file too. It limits the script to this Sheet and read-only Gmail.
  3. Deploy, New deployment, Web app. Execute as: Me. Who has access: Anyone. Approve the permissions.
  4. Copy the URL ending in /exec and paste it above.
