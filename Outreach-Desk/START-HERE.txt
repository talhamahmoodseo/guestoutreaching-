OUTREACH DESK 0.12 - CHROME EXTENSION

1. Extract this ZIP to a permanent folder.
2. Open chrome://extensions in Chrome.
3. Enable Developer mode.
4. Click Load unpacked.
5. Select Outreach-Desk/extension (the folder containing manifest.json).
6. Open the extension icon and click Open research workspace.

UPGRADING? Back up your current data first in Settings.
To keep the same extension identity, replace the files inside its EXISTING extension
folder and click Reload in Chrome. Installing from another folder creates separate
storage. Restore your JSON backup if that happens. Do not uninstall your old copy
before backing it up.

AFTER ANY UPGRADE, CLICK RELOAD. If the dashboard shows a red banner about the engine
version, the old background engine is still running and nothing else should be
investigated until you have reloaded.

Read README.md for the four sections, the three connection types, metric filters and
limits. For the output Sheet and Gmail checks, follow sheets-apps-script/SETUP.md.
No npm installation or build step is needed to use the extension.

This extension does not send email and does not submit contact forms. Sender profiles
are draft identities, not authenticated inbox connections.
